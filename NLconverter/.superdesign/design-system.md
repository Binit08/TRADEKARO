# Design System

## Colors
- **Background**: `#F8FAFC`
- **Foreground**: `#0F172A`
- **Sidebar Background**: `#0F172A`
- **Sidebar Border**: `#1E293B`
- **Accent Primary**: `#EAB308` (Neon Yellow)
- **Accent Secondary**: `#14B8A6` (Teal)
- **Status Win**: `#10B981`
- **Status Loss**: `#F43F5E`

## Fonts
- **Industrial**: JetBrains Mono, monospace
- **Body**: Inter, sans-serif

## Components
- **Sidebar Item**: Flex layout, Slate text, hover effects with yellow accent. Active state uses yellow border and background tint.
- **Input Field**: White background, Slate border, yellow focus ring, industrial font.
- **Metric Card**: White background, rounded corners, subtle shadow, hover effects.
- **Status Badges**: Small, rounded, colored background and text based on status.
- **Radio Buttons**: Custom styled radio buttons with yellow accent.
- **Assumption Box**: White box with subtle shadow, teal hover border.
