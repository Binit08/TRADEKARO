# Signal Engine

## What it is
The `SignalEngine` is the logical evaluator of the Backtesting system. It parses the JSON Abstract Syntax Tree (AST) generated by the NLconverter and evaluates it against the current tick's market data.

## Why it exists
By completely decoupling the evaluation of trading rules (Signal Engine) from the execution of trades (Execution Engine) and the calculation of data (Indicator Engine), the system prevents spaghetti code. This engine acts purely as a Boolean logic gate: "Is it time to trade? Yes or No."

## Data Flow
1. Instantiated with the user's parsed AST logic tree.
2. For every `MarketEvent` tick, the engine queries the `IndicatorEngine` for the current values of all required technical indicators (e.g., RSI, SMA).
3. Recursively evaluates the AST branches (e.g., `IF RSI > 70 AND SMA_50 < SMA_200`).
4. If the root condition evaluates to `True`, it emits a strict `SignalEvent` payload (containing the symbol, direction, and timestamp) to the `ExecutionSimulator`.
